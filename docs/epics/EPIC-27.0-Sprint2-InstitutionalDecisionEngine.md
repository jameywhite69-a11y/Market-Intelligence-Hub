# Version 27.0 — Sprint 2: Institutional Decision Engine

## Objective
Create a top-level institutional decision layer that answers whether an opportunity should be traded, watched, sized down, or avoided.

## Delivered Capabilities
- Institutional Decision Engine backend.
- Weighted decision factors.
- Classification: Elite Setup, Tradeable, Watch, Speculative, Avoid.
- Recommendation: Enter on Confirmation, Plan Trade, Watch Closely, Small Size Only, Avoid.
- Explainable decision summary.
- Opportunity Explorer Institutional Decision card.
- Technical API returns `decision` payload.
- Unit test coverage.
