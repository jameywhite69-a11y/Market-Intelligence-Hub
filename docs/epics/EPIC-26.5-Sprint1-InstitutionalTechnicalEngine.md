# Version 26.5 — Sprint 1: Institutional Technical Engine

## Objective

Move core technical calculations out of frontend heuristics and into a backend Market Intelligence Engine.

## Delivered Capabilities

- ATR calculation.
- Swing high / swing low.
- Pivot support and resistance.
- VWAP.
- EMA fast / slow trend structure.
- Trend direction and trend strength.
- Entry zone.
- Stop loss.
- Target 1 and Target 2.
- Risk/reward ratios.
- Technical API endpoint.
- Opportunity Explorer frontend enrichment.

## Notes

The engine currently uses the demo market data provider. Future sprints can connect it to live provider data and feed the scanner ranking engine directly.
