# Version 27.1 — Sprint 1: Opportunity Ranking Engine

## Objective

Begin Portfolio Intelligence by ranking opportunities across the current scan and showing which setups deserve priority attention.

## Delivered Capabilities

- Portfolio Intelligence package.
- Opportunity Ranking Engine.
- Momentum tracker.
- Allocation engine.
- Ranked opportunity model.
- Portfolio snapshot model.
- Opportunity Queue frontend widget.
- Portfolio summary cards.
- Scanner template integration.
- Unit test coverage.

## Notes

This sprint uses local scanner results for the frontend opportunity queue and a backend ranking engine for future API integration. Future sprints can connect backend decision payloads directly to scan responses and add exposure/correlation intelligence.
