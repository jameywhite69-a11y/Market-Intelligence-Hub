# CSV Import Tools

v23.2 adds browser-based CSV upload and diagnostics.

## UI

Go to:

```text
Market Data workspace
```

You can:

- Upload CSV files.
- Create a sample CSV for the active symbol.
- Run diagnostics.
- Switch provider to CSV.

## CSV format

```text
time,open,high,low,close,volume
```

Accepted aliases:

```text
date,o,h,l,c,v
```

## Filename examples

```text
NVDA.csv
NVDA_1D.csv
BTCUSD.csv
BTCUSD_1h.csv
```
